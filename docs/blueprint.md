# **App Name**: FinHub Central

## Core Features:

- Investor Dashboard: Personalized dashboard to view portfolio, reinvest funds, and track earnings.
- Client Dashboard: Dashboard to track loan status, repayment schedule, and lodge payments.
- Admin Dashboard: Central control panel with platform metrics, user management, and deal oversight.
- Deal Management: Create, view, and manage financing deals, categorized by funding status. Admins can automatically fund deals using a FIFO allocation of available investor and platform funds.
- User Management: Add, edit, and delete investor and client user profiles.
- Financial Approvals: Approve/reject financial requests like withdrawals, reinvestments, repayments, and terminations, which automatically distributes principal and ROI to the respective investors and the platform.
- Smart Deal Analyzer: An AI-powered tool to analyze financing proposals and provide assessments of viability, risk level, and key insights.
- Activity Tracker: Log significant user and admin actions in a filterable, reverse-chronological list for auditing.

## Style Guidelines:

- Primary color: Deep blue (#1E3A8A) for a professional and trustworthy feel.
- Background color: Light blue-gray (#F0F4F8) to provide a clean and modern backdrop.
- Accent color: Teal (#38B2AC) for highlights and interactive elements.
- Headlines: 'Space Grotesk' (sans-serif) for a modern, computerized feel.
- Body: 'Inter' (sans-serif) for a clean and readable user experience.
- Use professional and consistent icons from ShadCN UI's library.
- Employ a clean and structured layout using Tailwind CSS grid and flexbox.
- Subtle animations to enhance user interaction, such as button hovers and page transitions.
